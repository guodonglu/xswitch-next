# XSwitch Next

A lightweight request redirect tool built for developers and AI agents.

Chrome MV3 Side Panel • Native HTML/ES modules • Tailwind CSS • Redirect and CORS rules • Rule groups • MCP V2 • Agent Skill • Import/export • XSwitch compatibility.

Run `npm ci && npm run build`, then load `dist` as an unpacked extension. Open the Agent page for a setup prompt, or run `npm run mcp:install-host -- --extension-id <id>` for Windows/macOS/Linux. See [the main README](readme.md), [MCP reference](docs/mcp.md), and [acceptance report](docs/acceptance.md) for behavior and validation details.
